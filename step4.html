4. การจัดการข้อมูลจากฟอร์มและความปลอดภัย

การรับข้อมูลจากผู้ใช้งานคือจุดที่เสี่ยงที่สุด คุณต้องรู้วิธีการคัดกรองข้อมูลและป้องกันระบบจากการโจมตี


  • Request Handling: การรับค่าจากฟอร์ม HTML การดึงค่า Input แบบเจาะจง และการเก็บค่าเดิมไว้ในฟอร์มเมื่อเกิด Error (Old Input)
  • Validation: การตั้งกฎเกณฑ์ข้อมูล เช่น required, email, min:8 ผ่าน Form Request Classes และการนำข้อความ Error ไปโชว์หน้าเว็บ
  • CSRF Protection: การทำความเข้าใจช่องโหว่ปลอมแปลงคำขอ และการใส่ @csrf ในทุกๆ ฟอร์มที่เป็นการ POST ข้อมูล
  • Authentication: การติดตั้งระบบล็อกอิน สมัครสมาชิก และลืมรหัสผ่านแบบสำเร็จรูปด้วย Laravel Breeze
  • Authorization (เบื้องต้น): การตรวจสอบสิทธิ์ว่าผู้ใช้คนนี้มีสิทธิ์แก้ไขหรือลบข้อมูลนี้หรือไม่ ผ่านระบบ Gates หรือ Policies
