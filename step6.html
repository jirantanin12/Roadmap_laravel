6. ฟีเจอร์ระดับสูงและการนำขึ้นระบบจริง (Advanced & Deployment)

เมื่อระบบเริ่มใหญ่ขึ้น นี่คือทักษะที่ใช้ยกระดับประสิทธิภาพของแอปพลิเคชันและการทำงานร่วมกับทีม


  • Middleware: การสร้างด่านคัดกรอง Request เช่น การเช็คว่า User เป็น Admin หรือไม่ ก่อนที่จะอนุญาตให้เข้าไปถึง Controller
  • File Storage: การจัดการการอัปโหลดไฟล์/รูปภาพ การสร้าง Symlink (storage:link) เพื่อให้เข้าถึงไฟล์ภาพผ่าน URL สาธารณะได้
  • Version Control (Git): การเก็บประวัติโค้ดร่วมกับทีมผ่าน Git และ GitHub เข้าใจความสำคัญของการไม่นำไฟล์ .env หรือ vendor ขึ้นไปบน Repository
  • Deployment Basics: กระบวนการนำโค้ดขึ้นเซิร์ฟเวอร์จริง เช่น การเชื่อมต่อ SSH, การชี้ Domain name ไปที่โฟลเดอร์ public
  • Optimization: การใช้คำสั่งเคลียร์และสร้าง Cache ระบบใหม่บน Production เช่น config:cache, route:cache เพื่อเพิ่มความเร็วหน้าเว็บ
