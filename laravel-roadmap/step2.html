2. โครงสร้างหลักของการทำงาน (Core Concepts: MVC)

Laravel ทำงานแบบ MVC (Model-View-Controller) คุณต้องเข้าใจการไหลของข้อมูลตั้งแต่ผู้ใช้พิมพ์ URL จนถึงการแสดงผลหน้าเว็บ


  • Routing (routes/web.php): การสร้าง URL Pattern, การส่งพารามิเตอร์ผ่าน URL, การตั้งชื่อ Route (Named Routes) เพื่อความสะดวกในการอ้างอิง และ Route Groups
  • Controllers (C): การสร้าง Controller ผ่านคำสั่ง Artisan, การเขียนเมธอดเพื่อรับ Request, และการใช้ Resource Controllers สำหรับระบบ CRUD แบบมาตรฐาน
  • Views & Blade Engine (V): การเขียนโครงสร้างหน้าเว็บ HTML ผสมตัวแปร PHP, การใช้คำสั่งควบคุม @if, @foreach
  • Blade Layouts & Components: การสร้าง Template หลัก (Master Layout) ด้วย @extends และ @section เพื่อลดความซ้ำซ้อนของโค้ด HTML
  • Artisan Console: การใช้คำสั่ง php artisan ต่างๆ เช่น make:controller, route:list เพื่อช่วยทุ่นแรงในการเขียนโค้ด
