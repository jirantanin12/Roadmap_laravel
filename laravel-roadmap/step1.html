1. พื้นฐานที่ต้องแน่นก่อนเริ่ม Laravel (Prerequisites)

ก่อนจะกระโดดเข้าสู่ Framework การเข้าใจพื้นฐานของภาษาและเครื่องมือเหล่านี้จะช่วยให้คุณอ่านโค้ด Laravel ออกและแก้ปัญหาได้ไวขึ้น


  • PHP Basic & Modern Syntax: การใช้งาน Array Functions (map, filter), Arrow Functions, Null Coalescing Operator (??) และ Type Hinting
  • Object-Oriented Programming (OOP): หัวใจหลักของ Laravel คุณต้องเข้าใจเรื่อง Class, Object, Constructor, Inheritance (extends), Interface และ Traits
  • Composer (PHP Package Manager): การติดตั้งไลบรารีภายนอก การอ่านไฟล์ composer.json และการใช้คำสั่ง composer install หรือ update
  • Command Line Interface (CLI): การใช้ Terminal เบื้องต้น เช่น คำสั่งเปลี่ยนโฟลเดอร์ (cd), การสร้างไฟล์, และการรันเซิร์ฟเวอร์จำลอง
  • การจัดการ Local Environment: ความเข้าใจในการตั้งค่าโปรแกรมจำลองเซิร์ฟเวอร์ เช่น Laragon, XAMPP หรือ Laravel Herd
