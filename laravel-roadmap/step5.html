5. การยกระดับเป็นระบบหลังบ้าน (API Development)

ยุคปัจจุบัน Front-end มักถูกแยกส่วนออกไป (เช่น ใช้ React, Vue หรือทำแอปมือถือ) Backend จึงต้องสื่อสารด้วย API


  • API Routes: การแยกเส้นทางไปเขียนใน routes/api.php ซึ่งจะถูกตั้งค่าให้ไม่ใช้ Session หรือ CSRF
  • JSON Responses: การแปลงข้อมูลจาก Database ให้แสดงผลออกมาในรูปแบบ JSON Object เพื่อให้ระบบอื่นนำไปประมวลผลต่อได้
  • API Resources & Collections: เครื่องมือสำหรับจัดระเบียบและซ่อนข้อมูลบางฟิลด์ (เช่น รหัสผ่าน) ก่อนส่ง JSON ออกไปให้ผู้ใช้งาน
  • Laravel Sanctum: การทำระบบ Authentication สำหรับ API โดยการสร้างและตรวจสอบ API Token (Bearer Token) ในส่วนของ Header
  • Testing Tools: การใช้งานโปรแกรมภายนอกอย่าง Postman หรือ Thunder Client เพื่อจำลองการยิง Request ทดสอบ API
